# ThemeTrail

ThemeTrail — веб-приложение для формирования тематических прогулочных маршрутов по Вильнюсу.

Проект разработан в рамках преддипломной практики.

## Идея проекта

Обычные туристические сервисы в основном показывают популярные достопримечательности. Если пользователю интересна конкретная историческая или архитектурная тема, ему приходится самостоятельно искать связанные места в нескольких источниках и составлять маршрут.

ThemeTrail предлагает более узкий сценарий: пользователь выбирает тему и получает готовый набор связанных с ней объектов в рекомендуемом порядке посещения.

## Текущая версия

В прототипе реализованы три тематических маршрута:

- Исторический Вильнюс
- Архитектура XX века
- Еврейское наследие

Для каждого маршрута отображаются четыре объекта с:

- порядковым номером;
- изображением;
- названием;
- кратким описанием;
- адресом.

## Реализовано

- выбор тематического маршрута;
- переключение между тремя темами;
- отображение соответствующих объектов;
- рекомендуемый порядок посещения;
- адаптивный интерфейс;
- обработка состояния выбранного маршрута;
- автоматические тесты основных пользовательских сценариев;
- production-сборка проекта.
